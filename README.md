# 📚 Library Management System SQL Analysis Project

## Project Overview

This project demonstrates the design, implementation, and analysis of a Library Management System using SQL Server.

The project covers the complete SQL workflow:

* Database Design
* Data Import
* CRUD Operations
* Joins
* Aggregations
* Stored Procedures
* CTAS (Create Table As Select)
* Business Analysis Queries
* Performance Reporting

The system manages books, members, employees, branches, book issuance, returns, overdue tracking, and branch performance analysis.

---

## Project Objectives

The goal of this project is to simulate a real-world library management system and answer operational business questions using SQL.

### Key Objectives

* Manage book inventory.
* Track book issuance and returns.
* Monitor member activities.
* Analyze rental revenue.
* Generate branch performance reports.
* Identify overdue books and calculate fines.
* Automate library operations using stored procedures.

---

## Database Tables

### Books

Stores information about books available in the library.

### Branch

Stores branch information and managers.

### Employees

Stores employee records and branch assignments.

### Members

Stores registered library members.

### Issued_Status

Tracks books issued to members.

### ReturnStatus

Tracks returned books.

# Business Questions Solved

## CRUD Operations

### 1. Create a New Book Record

Added a new book into the Books table.

### 2. Update Member Information

Updated member details.

### 3. Delete Issued Records

Removed unwanted transaction records.

### 4. Retrieve Books Issued by an Employee

Tracked books issued by a specific employee.

### 5. Members with Multiple Borrowings

Identified members who borrowed more than one book.

---

## Reporting & Analysis

### 6. Book Issue Summary Table

Created a summary table showing the number of times each book has been issued.

### 7. Books by Category

Retrieved books belonging to a specific category.

### 8. Rental Revenue Analysis

Calculated rental income generated by each book category.

### 9. Recently Registered Members

Identified members who registered within the last five years.

### 10. Employee and Branch Reporting

Displayed employee details alongside branch and manager information.

### 11. Premium Books Analysis

Created a table containing books with rental prices above $5.

### 12. Books Not Yet Returned

Identified all currently borrowed books.

---

## Advanced Analytics

### 13. Overdue Book Detection

Identified members with overdue books exceeding the 30-day borrowing period.

Output included:

* Member ID
* Member Name
* Book Title
* Issue Date
* Days Overdue

### 14. Automated Return Processing

Developed a stored procedure that:

* Records returned books.
* Updates book availability status.
* Generates return confirmation messages.

### 15. Branch Performance Report

Generated a branch-level performance report showing:

* Number of books issued
* Number of books returned
* Total rental revenue

### 16. Active Member Identification

Created a table containing members who borrowed books within the last three months.

### 17. Top Performing Employees

Identified the top three employees based on the number of book issues processed.

### 18. Book Issuance Management Procedure

Built a stored procedure that:

* Checks book availability.
* Issues books automatically.
* Prevents issuing unavailable books.
* Returns custom error messages.

### 19. Overdue Books & Fine Calculation

Created a CTAS query that calculates:

* Number of overdue books per member.
* Total fines incurred.
* Fine rate: $0.50 per overdue day.
